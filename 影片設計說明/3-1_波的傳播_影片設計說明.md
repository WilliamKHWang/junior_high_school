## 二、AI 教學角色

AI 扮演「專業教導臺灣國中學生的顧問老師」，任務不是照念教材，而是讓學生看懂波的動作與公式之間的關係。

教學語氣應親切、清楚、有節奏；專有名詞第一次出現時先用動畫呈現，再給名稱。不得出現簡體中文或不符合臺灣教材的用語。

## 三、教材依據

- `local-content/references/國二理化/docs/理化-講義-3-1.pdf`
- `local-content/references/國二理化/docs/理化-自修-3-1.pdf`

重製前必須重新核對教材，尤其是：

- 波傳遞能量，不傳遞介質。
- 振源與介質的定義。
- 力學波與非力學波。
- 橫波、縱波與振動方向。
- 波峰、波谷、振幅、波長、週期、頻率。
- `f = 1 / T`。
- `v = fλ = λ / T`。
- 同一介質與相同狀態下，波速固定；頻率增大時波長縮短。

## 四、學習目標

學生看完影片後應能：

1. 說明波向前傳遞的是能量，不是介質本身。
2. 依振動方向與傳播方向判斷橫波和縱波。
3. 指出波峰、波谷、振幅與波長。
4. 說明週期與頻率互為倒數。
5. 使用 `v = fλ` 解一題波長計算。
6. 判斷同一條繩子上頻率改變時，波速與波長如何變化。

## 五、核心記憶句

- 波傳能量，不傳介質。
- 橫波：振動方向與傳播方向垂直。
- 縱波：振動方向與傳播方向平行。
- `f = 1 / T`。
- `v = fλ`。
- 同介質、相同狀態：`f` 越大，`λ` 越短。

## 七、旁白設計

- 本版採單一女聲旁白，整體像一位親切的理化老師。
- 共 8 段場景音檔，每段約 29～42 秒。
- 場景音檔：`audio_hsiaochen/scene_0.mp3` 至 `scene_7.mp3`。
- 旁白產生程式：`generate_narration.py`。
- 每個場景的完整文字同時保存在 `audio_hsiaochen/scene_*.txt`。
- 場景之間保留約 1.2 秒，旁白約在場景開始後 0.8 秒進入。

### 未來重製時的聲音改進

- 現版只有小晴女聲；若按目前系列統一規格重製，可加入阿哲男聲共同推理，但不可改變核心教學順序。
- 片頭不要留下明顯無聲；應在 0.5 秒內加入旁白或合適音效。
- 轉場空檔建議縮短為 0.25～0.6 秒，除非要刻意讓學生思考。
- 字幕應直接由旁白文字清單產生，逐句同步，而不是用場景進度粗略切換。

## 八、視覺與動畫規則

- 繩波的波形向右移動時，紅色介質點只能在原地上下振動。
- 縱波中，粒子只能左右往返；疏部與密部才向前傳播。
- 振幅箭頭必須從平衡位置量到波峰或波谷，不可畫成峰到谷。
- 波長應量相鄰同相位點，例如波峰到下一個波峰。
- 頻率變大時，畫面要同步顯示波長縮短，不能只改數字。
- 公式與代入步驟逐項出現，答案必須帶單位。
- 裝飾動畫不可搶過波形與紅點的運動。

## 十、驗收清單

- [ ] 波向前移，紅點只在原地振動。
- [ ] 橫波標示垂直，縱波標示平行。
- [ ] 波峰、波谷、振幅、波長位置正確。
- [ ] `f = 1 / T` 與 `v = fλ` 顯示正確。
- [ ] 例題答案為 `λ = 0.8 m`，且有完整步驟與單位。
- [ ] 快問快答答案為「波速不變、波長減半」。
- [ ] 所有畫面文字與字幕均為臺灣繁體中文。
- [ ] 影片不是靜態投影片，波、粒子、箭頭與公式皆有教學意義的動畫。
- [ ] 人物、字幕或提示卡沒有遮住波形、公式及答案。
- [ ] 實際播放檢查片頭、中段、例題與片尾的聲音及同步。

## 十一、不可任意更動的教學邏輯

1. 先用紅點建立「波傳能量、不傳介質」。
2. 再用振動方向與傳播方向分類橫波、縱波。
3. 學生看懂波形後，才引入五大名詞與公式。
4. 公式後立刻用例題與快問快答鞏固。
5. 結尾只保留四個最重要的記憶點。
